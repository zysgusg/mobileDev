# OUC夏季学期《移动软件开发》课程实验

## 介绍

本仓库记录个人在2026夏季学期《移动软件开发》的课程实验。课程以**移动应用开发基本编程能力**培养为目标，突出小程序基础知识的讲授，并结合实践案例及项目，使学习者从无到有，逐步掌握微信小程序的基本开发技能，为微信小程序的高级开发打下坚实基础。今年新增设鸿蒙实验环节。

## 内容

### 实验一：第一个微信小程序

**学习目标**： 1、学习使用快速启动模板创建小程序的方法；2、学习不使用模板手动创建小程序的方法。

**参考资料**：https://developers.weixin.qq.com/community/business/doc/0008ae90008ff80bd48838c5e5600d



### 实验二：名片小程序

**学习目标**：以制作一个名片小程序为案例，快速学习了解小程序前端开发。

**参考资料**：https://developers.weixin.qq.com/community/business/doc/000c869e5c46586bd688cd6175fc0d
